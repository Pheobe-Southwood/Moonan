# 0005：明文存储，唯一的例外是连接 token 的摘要

- 状态：接受
- 日期：rc1

## 背景

需求要求"所有数据都明文存储"。这包含 API Key。

## 决定

- **API Key 明文**写进 `~/.moonan/moonan.db` 的 `provider_cred.secret` 列（SQLite，WAL）。
- 服务只绑定 `127.0.0.1`，**不做认证**：可达性即授权。同时拒绝非本机来源与跨站 `Origin` 的 WebSocket 连接。
- 唯一非明文项：连接用的 token 只存 `sha256` 摘要（`setting.ws_token`）——因为它会出现在每次连接的握手与日志里，
  明文没有意义。README 与本节都记录这一点。

## 理由

- 明文是产品要求，不是疏忽；把它当作显式的取舍记录下来，比在代码里悄悄加密更诚实。
- 本机单用户应用引入加密的收益很低：密钥只能放在同一个文件旁边。

## 后果

- 好：数据库可读、可 grep、可用 sqlite3 直接排查问题；这是 rc1 阶段的主要调试手段。
- 差：**不要在共享机器或多用户环境运行**，README 首屏就写明这一点。
- 差：备份 `~/.moonan` 等于备份明文凭据。
